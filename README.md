### 🔵 Task 2 — TaskFlow API

**TaskFlow API** is a RESTful task management backend built with Node.js and Express.js.

The project demonstrates practical backend development concepts including CRUD operations, validation, HTTP status codes, middleware, error handling, JSON APIs, and cloud deployment.

#### Technologies

* Node.js
* Express.js
* JavaScript
* CORS
* Nodemon
* Vercel

#### Key Features

* Create tasks
* Retrieve all tasks
* Retrieve a task by ID
* Update tasks
* Delete tasks
* Request validation
* HTTP status code handling
* 404 route/resource handling
* Centralized error handling
* Health check endpoint
* RESTful API structure
* Production deployment

#### Live API

🌐 [TaskFlow API — Vercel](https://task-flow-api-psi.vercel.app)

#### Repository

👉 [View Task 2 — TaskFlow API](https://github.com/areebamansoor49-eng/TaskFlow-API)
